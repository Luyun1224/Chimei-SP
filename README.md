# SP 演出紀錄儀表板

標準化病人（SP）演出線上登錄與年度時數統計。純前端網頁，免安裝、免伺服器。

## 使用方式
直接用瀏覽器開啟 `index.html`（或部署到 GitHub Pages）。

## 功能
- **登錄演出**：日期、單位、報到時間、演出開始／結束、教案主題、SP 姓名（可多位，以「、」或逗號分隔）、備註
- **明日演出提醒**：自動列出明天的場次，一鍵複製提醒訊息（可貼到 LINE）
- **📅 加入 Google 行事曆**：每筆紀錄可一鍵開啟 Google 行事曆新增活動（報到時間～演出結束）
- **儀表板**：年度場次、SP 總時數、參與人數、各 SP 年度時數長條圖、每月時數長條圖
- **SP 年度統計表**：每位 SP 的場次、演出時數、在院時數、服務單位、最近一次演出
- **篩選**：年度／單位／SP／關鍵字，所有統計同步更新
- **資料**：匯出 CSV（Excel 可開）、JSON 備份與匯入、載入範例資料

## 時數計算
- 演出時數 ＝ 演出開始 → 演出結束
- 在院時數 ＝ 報到時間 → 演出結束
- 一場有多位 SP 時，每位 SP 各自計入該場時數

## 資料儲存
目前存在瀏覽器 localStorage（換電腦或清除瀏覽器資料會不見），請定期「備份 JSON」。
下一階段可改接 Google 試算表 + Apps Script，達成多裝置同步與自動寫入 Google 行事曆、前一天自動提醒。
